# INCPT asset bank (Higgsfield)

Reusable material for the redesign reels, made in Higgsfield while the subscription credits were
still there. The full-resolution files live in the Higgsfield library of the account (search by job
id); this folder keeps what fits in the repository:

- `icons/` — the chrome 3D icons with real alpha (480–640 px, cut from the 2880 px originals)
- `../../renders/bank/` — review sheets of everything below (stills, clips, 3D models)

Full-resolution files can be pulled into the repo once the cloud environment allows the CDN hosts
`d8j0ntlcm91z4.cloudfront.net` (generations) and `d2ol7oe51mr4n9.cloudfront.net` (uploads). All
results are at `https://d8j0ntlcm91z4.cloudfront.net/user_3Gln7uLR9v15bOY3vDAsQKMvK9v/<file>`.

The material language follows the new logo: polished chrome with fine diagonal ribs and
lime / violet / teal iridescence. The official logo is never redrawn by a model in the final cut —
clips where the model reshapes it are marked; use the matte (`assets/style/logo_chrome.png`) or the
3D kit for the exact mark.
